SyntaxHighlightColors

@ApiStatus.Experimental
@Immutable
class SyntaxHighlightColors(val keyword: Color, val type: Color, val constant: Color, val functionCall: Color, val string: Color, val comment: Color, val number: Color, val builtin: Color, val propertyKey: Color, val operator: Color)

Defines the colors used to render each TokenType in a syntax-highlighted code block.

The default light and dark palettes are based on IntelliJ IDEA's "Light" and "Dark" editor color schemes, the two the New UI selects by default. Colors are intentionally not sourced from the Jewel UI theme palette — those are UI chrome colors, not editor token colors.

Use SyntaxHighlightColors.light and SyntaxHighlightColors.dark to get the built-in palettes, or construct your own instance to fully customize token colors.

Parameters

keyword

Color for language keywords (e.g., val, fun, class, if). Rendered bold.

type

Color for built-in or primitive types (e.g., String, Int, void, bool).

constant

Color for language constants (e.g., true, false, null, nil). Rendered italic.

functionCall

Color for function and method names.

string

Color for string literals.

comment

Color for line and block comments. Rendered italic.

number

Color for numeric literals.

builtin

Color for well-known built-in functions and standard library identifiers. Rendered italic.

propertyKey

Color for keys in data languages, e.g. the "name" in JSON's "name": 1.

operator

Color for operators, e.g. +, ==, &&, |.
