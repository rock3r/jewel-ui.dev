        A horizontal strip of tabs that follows the standard visual styling with customizable appearance.

        Provides a scrollable container for displaying a row of tabs, with support for selection, hover effects, and automatic scrollbar visibility. The tabs can be closable or fixed, and support custom content layouts.

        Guidelines: on IJP SDK webhelp

        Usage example: Tabs.kt

        Swing equivalent: JTabbedPane

        Parameters:
        tabs - The list of tab data objects defining the content and behavior of each tab
        style - The visual styling configuration for the tab strip and its tabs
        modifier - Modifier to be applied to the tab strip container
        enabled - Controls the enabled state of the tab strip.
        interactionSource - The MutableInteractionSource that will be used to handle interactions with the tab strip
