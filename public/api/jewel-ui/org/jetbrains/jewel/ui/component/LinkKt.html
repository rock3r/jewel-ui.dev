        A clickable text link that follows the standard visual styling with customizable appearance.

        Provides a text link that can be clicked to trigger an action. The link supports various states including enabled/disabled, focused, and hovered, with optional underline behavior based on the style configuration.

        Guidelines: on IJP SDK webhelp

        Usage example: Links.kt

        Swing equivalent: JLabel with HTML link styling. ALso see ActionLink

        Parameters:
        text - The text to be displayed as a link
        onClick - Called when the link is clicked
        modifier - Modifier to be applied to the link
        enabled - Controls whether the link can be interacted with
        textStyle - The typography style to be applied to the link text
        overflow - How the text should handle overflow
        interactionSource - Source of interactions for this link
        style - The visual styling configuration for the link
