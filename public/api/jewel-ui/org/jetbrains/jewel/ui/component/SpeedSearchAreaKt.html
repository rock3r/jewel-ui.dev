        Creates a speed search area that provides keyboard-driven search functionality for its content.

        This composable enables users to quickly filter or highlight items by typing characters. The search input appears as an overlay when the user starts typing, and matches are computed using the provided matcherBuilder.

        Parameters:
        modifier - The modifier to be applied to the container.
        matcherBuilder - A function that creates a SpeedSearchMatcher from the search text.
        styling - The visual styling for the speed search input overlay.
        textFieldStyle - The styling for the text field within the search overlay.
        textStyle - The text style for the search input text.
        searchMatchStyle - The styling for highlighting matched text in search results.
        interactionSource - The interaction source for tracking focus state.
        dismissOnLoseFocus - Whether focus loss or renderer-level outside dismissal hides the search input.
        content - The content to be displayed within the speed search area.
