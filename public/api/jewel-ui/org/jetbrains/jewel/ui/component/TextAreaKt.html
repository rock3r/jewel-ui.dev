        A multi-line text input component that follows the standard visual styling.

        Provides a scrollable text editing area that can display and edit multiple lines of text. The component includes standard text editing capabilities, scrollbars when needed, and platform-specific key bindings.

        Guidelines: on IJP SDK webhelp

        Usage example: TextAreas.kt

        Swing equivalent: JBTextArea

        Parameters:
        state - The state object controlling the text content and selection
        modifier - Modifier to be applied to the text area
        enabled - Controls whether the text area can be interacted with
        readOnly - Controls whether the text can be modified
        inputTransformation - Transforms text input before it appears in the text area
        textStyle - The typography style to be applied to the text
        keyboardOptions - Options controlling keyboard input behavior
        onKeyboardAction - Handler for keyboard actions
        lineLimits - Constraints on the number of lines allowed
        onTextLayout - Callback for text layout changes
        interactionSource - Source of interactions for this text area
        style - The visual styling configuration for the text area
        outline - The outline style to be applied to the text area
        placeholder - Content to display when the text area is empty
        decorationBoxModifier - Modifier to be applied to the decoration box
        outputTransformation - Transforms text output for display
        undecorated - Whether to show the text area without decorations
        scrollState - The state object controlling scrolling behavior
        scrollbarStyle - The visual styling configuration for the scrollbar

        A multi-line text input component that follows the standard visual styling.

        Note: you should prefer the state-based variant whenever possible. When the TextFieldState-based variant will reach feature parity with this variant, we'll deprecate this variant and, after some time, remove it.

        Provides a scrollable text editing area that can display and edit multiple lines of text. The component includes standard text editing capabilities and platform-specific key bindings. It cannot display scrollbars.

        Guidelines: on IJP SDK webhelp

        Usage example: TextAreas.kt

        Swing equivalent: JBTextArea

        Parameters:

        onValueChange - A lambda invoked when the internal state changes
