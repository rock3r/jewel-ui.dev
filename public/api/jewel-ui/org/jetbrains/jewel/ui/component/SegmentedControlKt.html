        A segmented control component that displays a horizontal group of mutually exclusive buttons. Each segment represents an option that can be selected, with only one segment being selected at a time. The control provides built-in keyboard navigation and focus management.

        Segmented controls are commonly used for:

        • Switching between different views

        • Selecting from a small set of mutually exclusive options

        • Filtering content with different criteria

        Guidelines: on IJP SDK webhelp

        Example usage: SegmentedControls

        Swing equivalent: JBRadioButton

        Parameters:
        buttons - List of SegmentedControlButtonData that define the segments to display.
        modifier - Modifier to be applied to the control
        enabled - Controls the enabled state of the entire control.
        style - The SegmentedControlStyle that defines visual properties like colors and metrics for the control container
        buttonStyle - The SegmentedControlButtonStyle that defines visual properties for individual segments
        textStyle - The TextStyle to be applied to text content within the segments
        interactionSource - The MutableInteractionSource that will be used to handle interactions with the control
