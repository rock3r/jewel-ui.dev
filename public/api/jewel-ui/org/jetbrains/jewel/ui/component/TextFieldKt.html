        A single-line text input component that follows the standard visual styling.

        Provides a text input field for single-line text entry with optional leading and trailing icons, placeholder text, and various text input features. The component supports standard text editing capabilities and platform-specific key bindings.

        Guidelines: on IJP SDK webhelp

        Usage example: TextFields.kt

        Swing equivalent: JBTextField and JTextField

        Parameters:
        state - The state object controlling the text content and selection
        modifier - Modifier to be applied to the text field
        enabled - Controls whether the text field can be interacted with
        readOnly - Controls whether the text can be modified
        inputTransformation - Transforms text input before it appears in the field
        textStyle - The typography style to be applied to the text
        keyboardOptions - Options controlling keyboard input behavior
        onKeyboardAction - Handler for keyboard actions
        onTextLayout - Callback for text layout changes
        interactionSource - Source of interactions for this text field
        style - The visual styling configuration for the text field
        outline - The outline style to be applied to the text field
        placeholder - Content to display when the text field is empty
        leadingIcon - Optional icon to display before the text
        trailingIcon - Optional icon to display after the text
        outputTransformation - Transforms text output for display
        undecorated - Whether to show the text field without decorations
