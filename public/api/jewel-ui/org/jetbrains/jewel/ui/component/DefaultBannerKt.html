         final static Unit ,kotlin.jvm.functions.Function0,kotlin.jvm.functions.Function1,org.jetbrains.jewel.ui.component.styling.DefaultBannerStyle,.)>InformationDefaultBanner(String text, <Error class: unknown class> modifier, Function0<Unit> icon, Function1<<Error class: unknown class>, Unit> actions, DefaultBannerStyle style, <Error class: unknown class> textStyle)

        Displays an informational editor banner providing a context-aware message to the user, styled with the default "information" theme.

        The banner includes an optional icon, customizable actions, and a text message. Its primary purpose is to provide non-intrusive, informative feedback in the editor area.

        Parameters:
        text - the main text content of the banner, succinctly describing the message or context.
        modifier - a Modifier for customizing the layout and appearance of the banner.
        icon - a composable representing an optional icon displayed on the left side of the banner, by default it shows the general "information" icon, in a 16x16 dp Box.
        actions - an optional row of clickable components (e.g., links or buttons) placed at the end of the banner.
        style - defines the visual styling of the banner, adapting to the default "information" theme of the IJ UI.
        textStyle - the styling applied to the banner's text content, using the default text style from the Jewel theme.
