A Got It tooltip component that provides contextual information about new or changed features.

Got It tooltips are specialized popups (called "Balloons" in the Swing implementation) that:

  • Appear near UI elements to guide users

  • Can display icons or step numbers

  • Support rich content (headers, links, images, buttons)

  • Auto-hide after a timeout (optional, mutually exclusive with buttons)

  • Display an arrow pointing to the target element

Important: When a timeout is set, buttons are automatically hidden. The tooltip will auto-dismiss after the timeout duration. This matches the Swing implementation behavior.

Dismissal: This component never removes itself from the UI. When a button is clicked, or when the timeout elapses, onDismiss is called — but the tooltip stays visible until the caller reacts by setting visible to false. Always wire onDismiss to update your state, otherwise the tooltip cannot be closed.

Guidelines: on IJP SDK webhelp

Swing equivalent: GotItTooltip

Usage example:

var showTooltip by remember { mutableStateOf(false) }

GotItTooltip(
    text = "This is a new feature!",
    visible = showTooltip,
    onDismiss = { showTooltip = false },
) {
    Button(onClick = { showTooltip = true }) {
        Text("Click me")
    }
}

Controls the visibility of the component.

onDismiss

Called when a button is clicked, the timeout elapses, or the user presses Escape. Must set visible to false to actually hide the tooltip; without this the popup remains on screen indefinitely.

modifier

Modifier to apply to the content wrapper

header

Optional header text displayed above the main content

iconOrStep

Optional icon or step number to display (mutually exclusive)

buttons

Button configuration (primary and optional secondary button). Each button's GotItButton.action runs as a side effect before onDismiss is called automatically.

link

Type of link to display below the text

image

Optional image to display at the top of the tooltip

maxWidth

Optional fixed text width. When set, auto-extension (280→328 dp) is disabled. Ignored when an image is present — the image width always takes priority. Matches GotItComponentBuilder.withMaxWidth().

timeout

Auto-hide timeout. Buttons are hidden and onDismiss is called after this duration elapses. Use Duration.INFINITE (the default) to disable the timeout.

gotItBalloonPosition

Which side of the target component the balloon appears on.

anchor

The alignment point on the target component that the balloon's arrow points to.

padding

Extra gap between the balloon arrow tip and the anchor point. Pushes the balloon away from the component it is anchored to.

onShow

Callback invoked when the tooltip is displayed

onEscapePress

Optional side effect invoked when the user presses Escape. onDismiss is always called on Escape regardless of whether this is set.

style

Visual styling configuration

content

The target component to which this tooltip is anchored

A Got It tooltip component that provides contextual information about new or changed features, with support for rich body content (bold, code, inline links, browser links).

Build the body with buildGotItBody:

GotItTooltip(
    body = buildGotItBody {
        append("Press ")
        bold("Resume")
        append(", or ")
        link("open the docs") { openUrl("https://example.com") }
        append(".")
    },
    visible = showTooltip,
    onDismiss = { showTooltip = false },
) { ... }
