SpeedSearchState

@ApiStatus.Experimental
interface SpeedSearchState

State holder for speed search functionality, managing search text, visibility, and match results.

This interface provides access to the current search state and methods for controlling the search behavior. Use rememberSpeedSearchState to create an instance of this state.

Custom speed-searchable components must call attach to synchronize and actually activate SpeedSearchState. Jewel's built-in speed-searchable components do this automatically.
