A tooltip component that follows the standard visual styling.

Provides a floating tooltip that appears when hovering over or focusing the target content. The tooltip follows platform conventions for timing, positioning, and appearance, supporting both mouse and keyboard navigation.

Guidelines: on IJP SDK webhelp

autoHideBehavior

The delay before the tooltip is automatically hidden. Jewel offers three options, matching Swing behavior. AutoHideBehavior.Normal is a shorter delay (10 seconds) to be used when the tooltip text is a single line. AutoHideBehavior.Long is a longer delay (30 seconds) to be used when the tooltip text is multi-line. AutoHideBehavior.Never to never hide the tooltip. AutoHideBehavior.Normal and AutoHideBehavior.Long durations can be altered using org.jetbrains.jewel.ui.component.styling.TooltipMetrics.
