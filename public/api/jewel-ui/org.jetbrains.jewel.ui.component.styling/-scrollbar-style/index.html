ScrollbarStyle

@Stable
class ScrollbarStyle(val colors: ScrollbarColors, val metrics: ScrollbarMetrics, val trackClickBehavior: TrackClickBehavior, val scrollbarVisibility: ScrollbarVisibility)

Defines the visual style for a scrollbar. This includes colors, metrics, and behaviors.

The style can be accessed through JewelTheme.scrollbarStyle.

Parameters

colors

The set of colors used to paint the scrollbar.

metrics

The sizing and shape properties of the scrollbar.

trackClickBehavior

The behavior of the scrollbar track when clicked.

scrollbarVisibility

The visibility behavior of the scrollbar.
