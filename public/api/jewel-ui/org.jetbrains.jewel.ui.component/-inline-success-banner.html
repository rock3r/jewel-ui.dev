InlineSuccessBanner

@Composable
fun InlineSuccessBanner(@Nls text: String, modifier: Modifier = Modifier, @Nls title: String? = null, icon: @Composable () -> Unit? = { Icon(AllIconsKeys.Status.Success, null) }, linkActions: BannerLinkActionScope.() -> Unit? = null, iconActions: BannerIconActionScope.() -> Unit? = null, style: InlineBannerStyle = JewelTheme.inlineBannerStyle.success, textStyle: TextStyle = JewelTheme.defaultTextStyle)

Displays a success inline banner providing information about the successful completion of an operation.

Guidelines: on IntelliJ Platform SDK webhelp (note: there are no guidelines for inline banners)

Swing equivalent: InlineBanner

Usage example: Banners.kt

InlineSuccessBanner(
    text = "Project indexed successfully.",
    actionsContent = {
        action("Dismiss", onClick = { /* Handle dismiss action */})
        iconAction(AllIconsKeys.General.Close, "Close button", null, onClick = {  })
    }
)

Parameters

text

The primary content of the banner, briefly describing the information it conveys.

modifier

Modifier to apply to the banner.

title

An optional title, rendered in bold, that appears above the text.

icon

Slot for an optional icon displayed on the left of the text or title. If null, there is no icon. By default, it is the AllIconsKeys.Status.Success icon.

linkActions

A block within the BannerLinkActionScope to define optional action items for the banner. If not provided, no actions will be rendered. Please note that this block will automatically fold the actions into a "More" dropdown menu if there are more than 3 actions or there is not enough space to fit the actions.

iconActions

A block within the BannerIconActionScope to define optional icon actions, such as closing the banner. Shows at the top right of the banner. If not provided, no icon actions will be rendered.

style

An InlineBannerStyle used to style the banner. The default is the theme's JewelTheme.inlineBannerStyle.success.

textStyle

The base TextStyle used by the text and title. Note that the title always has a Bold weight.

Displays a success inline banner providing information about the successful completion of an operation.

Use this banner to provide relevant, non-critical information in a compact layout.

Guidelines: on IntelliJ Platform SDK webhelp (note: there are no guidelines for inline banners)

        iconAction(AllIconsKeys.General.Close, "Close button", null, onClick = {  })
    }

    Markdown("Project indexed **successfully**.")
}
