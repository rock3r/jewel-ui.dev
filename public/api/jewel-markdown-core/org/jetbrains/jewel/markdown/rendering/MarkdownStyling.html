Package org.jetbrains.jewel.markdown.rendering

Class MarkdownStyling

  • All Implemented Interfaces:
    
public final class MarkdownStyling

    Holds all styling configuration for rendering Markdown content, grouping per-block-type styling classes for paragraphs, headings, block quotes, code blocks, lists, images, thematic breaks, and HTML blocks.
