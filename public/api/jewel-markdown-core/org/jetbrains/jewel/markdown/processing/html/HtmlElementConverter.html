         MarkdownBlock convert(MarkdownHtmlNode.Element htmlElement, Function1<MarkdownHtmlNode.Element, List<MarkdownBlock>> convertChildren, Function1<List<MarkdownHtmlNode>, List<InlineMarkdown>> convertInlines)

        Converts an HTML element into a Markdown block by applying child element and inline element conversion logic.

        Implement this method if the HTML element should be converted into a Markdown block.

        Parameters:
        htmlElement - the HTML element to be converted into a Markdown block
        convertChildren - a lambda to convert child elements of the given HTML element into a list of Markdown blocks
        convertInlines - a function to convert inline elements into a list of inline Markdown elements
        Returns:

        the resulting Markdown block or null if the conversion is not applicable for the given element
