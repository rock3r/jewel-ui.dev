        Parameters:
        extensions - Extensions to use when processing the Markdown (e.g., to support parsing custom block-level Markdown).
        markdownMode - Indicates a scenario of how the file is going to be presented.
        commonMarkParser - The CommonMark Parser used to parse the Markdown.
        parseEmbeddedHtml - If true, a subset of native HTML elements will be parsed as Markdown blocks.

         final List<MarkdownBlock> processMarkdownDocument(String rawMarkdown)

        Parses a Markdown document, translating from CommonMark 0.31.2 to a list of MarkdownBlock. Inline Markdown in leaf nodes is contained in InlineMarkdown, which can be rendered to an androidx.compose.ui.text.AnnotatedString by using DefaultInlineMarkdownRenderer.renderAsAnnotatedString.

        Parameters:
        rawMarkdown - the raw Markdown string to process.
