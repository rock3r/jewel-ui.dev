Package org.jetbrains.jewel.foundation.theme

Class ThemeDefinition

  • All Implemented Interfaces:
    
public final class ThemeDefinition

    Defines all visual properties of a Jewel theme: its name, dark/light mode, global colors and metrics, text styles, content color, color palette, icon data, and disabled appearance values.
