      • rememberSelectableLazyListState

         final static SelectableLazyListState rememberSelectableLazyListState(Integer initialFirstVisibleItemIndex, Integer initialFirstVisibleItemScrollOffset, SelectionMode selectionMode, List<Object> initialSelectedKeys)

        Remembers a legacy SelectableLazyListState.

        The underlying LazyListState and SelectableLazyListState are created once and reused across recompositions. Parameters are treated as initial values and are not reapplied after the first composition.

        initialSelectedKeys are normalized once at creation time using normalizeFor:

        • SelectionMode.None: all keys are ignored.

        • SelectionMode.Single: only the first key is kept.

        • SelectionMode.Multiple: all keys are kept (deduplicated in insertion order).

        Initial key application does not trigger SelectableLazyColumn's onSelectedIndexesChange on the first composition.

        Parameters:
        initialFirstVisibleItemIndex - Initial index of the first visible item, used only at creation time.
        initialFirstVisibleItemScrollOffset - Initial scroll offset of the first visible item, used only at creation time.
        selectionMode - Legacy selection mode metadata and normalization mode used at creation time.
        initialSelectedKeys - Keys that should be selected before the first user interaction.
