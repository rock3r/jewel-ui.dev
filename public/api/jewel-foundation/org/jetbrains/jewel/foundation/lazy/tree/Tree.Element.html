Package org.jetbrains.jewel.foundation.lazy.tree

Interface Tree.Element

  • All Implemented Interfaces:
    
public interface Tree.Element<T extends Object>

    An element in the tree, holding data plus depth, childIndex, a parent pointer, and next/previous pointers into the tree's flattened linked list.
