GlobalColors

@Immutable
class GlobalColors(val borders: BorderColors, val outlines: OutlineColors, val text: TextColors, val panelBackground: Color, val toolwindowBackground: Color)

Defines the global colors used in the Jewel UI. These colors are not component-specific and can be used to style any part of the application.

Parameters

borders

The colors used for component borders.

outlines

The colors used for component outlines, which are drawn outside the borders.

text

The colors used for text elements.

panelBackground

The background color for panels and windows.

toolwindowBackground

The background color for tool windows. It is Unspecified outside of the IDE.
