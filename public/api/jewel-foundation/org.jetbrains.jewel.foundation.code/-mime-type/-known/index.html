Known

object Known

Deprecated

The MimeType class is deprecated in favor of using the code block info strings (e.g., "kt", "python"). This class creates an unnecessary layer of abstraction and requires manual maintenance to support new languages. Use the new `highlight(code, language)` function to handle language resolution automatically.

Predefined MimeType constants for well-known programming languages and content types.
