grayOrNull

fun grayOrNull(index: Int): Color?

Retrieves a gray color from the palette by its index, or null if the index is out of bounds.

Palette indices start at 1 (or 10 for Islands themes); how many entries exist for a color depends on the Look and Feel. Some LaFs may only have a partial palette, or none at all.

Return

The Color at the specified index, or null if the index is out of bounds.

Parameters

index

The 1-based (or 10-based for Islands themes) index of the color to retrieve. Only values of 1 and above are valid.
