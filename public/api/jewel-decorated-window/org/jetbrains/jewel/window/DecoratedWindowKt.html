        A Compose window with custom JetBrains Runtime (JBR) window decorations, including support for a custom TitleBar. Requires the application to run on JetBrains Runtime; an error is thrown at runtime if JBR is not available.

        On Linux, the window is rendered undecorated with a 1dp border drawn by Compose to simulate a native frame.

        Parameters:
        onCloseRequest - Callback invoked when the user requests to close the window.
        state - The WindowState controlling the window's size and placement.
        visible - Whether the window is visible.
        title - The title shown in the OS window frame and taskbar.
        icon - The icon shown in the OS window frame and taskbar.
        resizable - Whether the user can resize the window.
        enabled - Whether the window is enabled for user interaction.
        focusable - Whether the window can receive focus.
        alwaysOnTop - Whether the window is always displayed on top of other windows.
        onPreviewKeyEvent - Callback invoked for key events before they are dispatched to children.
        onKeyEvent - Callback invoked for key events after they are dispatched to children.
        style - The DecoratedWindowStyle controlling the window frame's visual appearance.
        content - The composable content displayed inside the window, scoped to a DecoratedWindowScope.
